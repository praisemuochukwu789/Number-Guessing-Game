# Number Guessing Game CLI

A command-line number guessing game built in Python. This project is part of the [roadmap.sh backend beginner track](https://roadmap.sh/projects/number-guessing-game).

**Features:**
* Three difficulty levels (Easy, Medium, Hard) with limited attempts.
* Robust input validation to prevent crashes from invalid data.
* Tracks attempts and elapsed time per round.
* *Replay Support: Allows playing multiple rounds back-to-back without restarting the script.

**How to Run:**
Ensure you have Python installed, then run:
```bash
python guess.py
